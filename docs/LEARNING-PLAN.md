# Java 全课程学习计划

## 学习目标

这套课程面向已经掌握 JavaScript/TypeScript 和前端开发的学习者。最终目标不是只会写 Java 语法，而是能够独立完成一个可供前端调用的 Java 后端：设计 REST API、处理业务规则、访问数据库、编写测试、实现登录鉴权，并完成本地部署与前后端联调。

课程采用小步练习方式。每一课只引入少量新概念，并尽量与熟悉的前端概念进行对照。

一课只有同时满足以下条件才算完成：

1. 所有 `TODO` 都实现了题目要求，而不只是能够编译。
2. 实际输出与讲义中的预期输出一致。
3. 异常分支使用正确的异常类型和消息。
4. JUnit 测试断言真正验证目标行为，没有假通过。
5. 完整 Maven 测试通过。
6. 课程状态、README 和 GitHub 代码同步更新。

## 学习方法

- 先预测结果，再运行代码验证。
- 遇到不熟悉的表达式时，从右向左分析返回值和类型。
- 将 Java 写法翻译成对应的 TypeScript，再翻译回来。
- 每次只解决一个编译错误，不同时修改多个不确定点。
- 保留已经完成的课程，通过新包创建下一课，方便随时回顾。
- 重点理解为什么使用某种类型、异常或分层，而不是只记住代码模板。
